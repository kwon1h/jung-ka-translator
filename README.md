# 중카 번역기

중국 카트라이더를 위한 Windows 실시간 게임 번역기입니다. 선택한 게임 창을 읽어 채팅·메뉴·시스템 문구를 한국어로 번역하고, 별도 결과 창 또는 원문 위치의 화면 오버레이로 보여 줍니다.

[최신 버전 다운로드](https://github.com/kwon1h/jung-ka-translator/releases/latest)

![중카 번역기 최신 화면](docs/images/app-main-language-model.png)

## 핵심 기능

| 기능 | 제공 내용 |
| --- | --- |
| 번역 모드 | 채팅 번역과 전체화면 번역 |
| 위치 기반 표시 | OCR이 읽은 자리 위에 번역을 표시하며, 번역끼리 겹쳐도 위치를 옮기지 않음 |
| 영역 편집 | 여러 번역 영역·제외 영역을 추가하고 이동·크기 조절·삭제 |
| 언어 설정 | 내려받은 게임 언어 목록에서 원문 언어를 고르는 간단한 흐름 |
| OCR 모델 | 언어 드롭다운에서 필요한 모델만 내려받고, 준비된 언어만 게임 언어 목록에 표시 |
| 오버레이 | 글꼴·색상·배경·투명도·테두리·표시 시간 설정과 방송/화면 공유 표시 |
| 유저 사전 | 화면을 드래그해 OCR 원문을 채운 뒤 원하는 한국어 표현 등록 |

## 설치와 시작

1. [Releases](https://github.com/kwon1h/jung-ka-translator/releases)에서 `GameOverlayTranslator.exe` 하나를 받습니다.
2. 원하는 폴더에 두고 실행합니다.
3. 카트라이더를 창모드 또는 테두리 없는 전체화면으로 실행합니다.
4. 번역기에서 게임 창을 고르고, 번역 모드와 표시 방식을 선택합니다.
5. 필요하면 `영역 편집`으로 OCR 범위를 잡은 다음 `번역 시작`을 누릅니다.

독점 전체화면에서는 외부 오버레이가 보이지 않을 수 있으므로 창모드 또는 테두리 없는 전체화면을 권장합니다.

## 사용하는 법

### 1. 게임 언어와 번역 언어

`게임 언어 및 번역 언어`를 열어 게임 원문과 결과 언어만 고릅니다. OCR 엔진을 따로 고를 필요는 없습니다.

- **게임 언어**에는 이미 내려받은 언어만 표시됩니다.
- **언어 모델** 드롭다운에서 중국어(간체), 영어, 일본어, 한국어, 아랍어, 힌디어, 타밀어, 텔루구어, 칸나다어 중 필요한 언어를 고릅니다.
- 준비된 모델은 `준비됨`으로 비활성화되고, 아직 없는 모델만 `다운로드`할 수 있습니다.

### 2. 영역 편집

게임 미리보기에서 기존 영역을 보며 편집합니다.

- **좌클릭 드래그:** 번역 영역 추가
- **우클릭 드래그:** 제외 영역 추가
- **기존 영역 드래그:** 위치·크기 조절
- **Delete:** 선택한 영역 삭제

채팅은 채팅 줄 전체만 포함하도록 좁게 잡고, 순위표·미니맵·장식처럼 필요 없는 곳은 제외 영역으로 빼면 인식 품질과 속도가 좋아집니다.

### 3. 표시 방식

- **채팅 번역:** 별도 결과 창 또는 화면 오버레이를 선택할 수 있습니다.
- **전체화면 번역:** 선택 영역 오버레이로 표시됩니다.
- 오버레이는 원문 OCR 좌표를 그대로 사용합니다. 밀집한 화면에서는 번역이 서로 겹칠 수 있지만, 임의로 다른 자리로 이동하지 않습니다.

### 4. 오버레이 스타일

`오버레이 스타일`에서 가독성 프리셋, 전체 투명도, 글꼴·글자 크기·테두리·색상·배경을 설정합니다.

- 번역 유지시간: `0.1~5초`, `0.1초` 단위, 기본 `4초`
- 마지막 글꼴과 스타일 설정은 다음 실행에도 유지
- `화면 공유/방송 시 오버레이 표시`를 켜면 디스플레이 캡처에 오버레이 포함

## 유저 사전: 화면을 드래그해 직접 번역 만들기

반복되는 게임 용어·아이템·빠른 답장·OCR 오인식 문구는 유저 사전에 원하는 한국어로 등록할 수 있습니다.

1. 왼쪽 `사전` 탭에서 `화면 OCR`을 선택합니다.
2. 게임 미리보기에서 원문이 있는 곳을 좌클릭 드래그합니다.
3. `OCR 실행`으로 원문 단어를 자동 입력합니다.
4. `대체 번역어`에 원하는 한국어를 적고 분류를 고른 뒤 `사전 단어 추가`를 누릅니다.

같은 원문이 인식되면 유저 사전이 번역 API보다 먼저 적용됩니다.

## 번역 서비스

설정 탭에서 다음 방식을 선택합니다.

- **DeepL API:** 권장 방식이며 개인 API 키가 필요합니다.
- **Google 번역:** API 키 없이 사용하는 비공식 방식으로, 요청이 많으면 제한될 수 있습니다.
- **Google Apps Script:** 사용자가 배포한 개인 웹 앱 URL을 사용합니다.
