# OCR 엔진

OCR 엔진은 게임 화면의 글자를 텍스트로 읽는 기능입니다. 중카 번역기는 `Windows OCR`과 `PaddleOCR(OpenVINO)`를 지원합니다.

![OCR 엔진 설정 위치](../ui-preview.png)

## 엔진 선택 기준

| 엔진 | 장점 | 단점 | 추천 상황 |
| --- | --- | --- | --- |
| Windows OCR | Windows 기본 기능을 사용해 설정이 단순합니다. | 중국어/일본어 언어 팩이 없으면 사용할 수 없고, 게임 글꼴 인식이 불안정할 수 있습니다. | 빠르게 시작하거나 기본 OCR로 충분할 때 |
| PaddleOCR(OpenVINO) | 중국어/일본어 게임 화면 인식 품질이 더 좋은 편입니다. | 첫 모델 준비가 필요할 수 있고 Windows OCR보다 인식 시간이 오래 걸립니다. | 인식 품질이 중요하고 약간의 지연을 감수할 수 있을 때 |

## Windows OCR

Windows OCR은 Windows에 설치된 OCR 언어 리소스를 사용합니다. 앱에서 `중국어(간체)` 또는 `일본어`를 선택했는데 해당 Windows OCR 언어를 사용할 수 없으면 `Windows OCR 언어 팩을 사용할 수 없습니다.`와 같은 오류가 날 수 있습니다.

### Windows 언어 설치 방법

Windows 11 기준:

1. Windows `설정`을 엽니다.
2. `시간 및 언어`를 선택합니다.
3. `언어 및 지역`을 엽니다.
4. `기본 설정 언어`에서 `언어 추가`를 선택합니다.
5. OCR에 사용할 언어를 검색해 추가합니다.
   - 중국어 OCR: `중국어(간체)` 또는 `Chinese (Simplified)`
   - 일본어 OCR: `일본어` 또는 `Japanese`
6. 설치 옵션 화면에서 사용 가능한 언어 기능을 함께 설치합니다.
7. 설치가 끝나면 중카 번역기를 다시 실행합니다.
8. 앱의 `OCR 언어`에서 설치한 언어를 선택하고 다시 번역을 시작합니다.

Windows 10에서도 흐름은 비슷합니다. `설정` > `시간 및 언어` > `언어`에서 언어를 추가하고 언어 옵션을 설치합니다.

Microsoft의 Windows 언어 설정 안내는 [공식 지원 문서](https://support.microsoft.com/en-US/windows/manage-the-language-and-keyboard-input-layout-settings-in-windows-12a10cb4-8626-9b77-0ccb-5013e0c7c7a2)를 참고하세요.

### 실패했을 때 확인할 것

- 언어를 추가한 직후라면 앱을 완전히 종료했다가 다시 실행합니다.
- 중국어와 일본어를 모두 쓰려면 두 언어를 각각 설치합니다.
- Windows 표시 언어를 바꿀 필요는 없습니다. OCR 대상 언어가 기본 설정 언어에 설치되어 있으면 됩니다.
- 그래도 실패하면 PaddleOCR로 전환해 보세요.

## PaddleOCR(OpenVINO)

PaddleOCR은 OpenVINO 기반 OCR 엔진입니다. Windows OCR보다 중국어/일본어 게임 글자 인식이 좋은 편이지만, 모델 로딩과 OCR 처리 시간이 더 오래 걸릴 수 있습니다.

### 앱에서 선택하는 방법

1. 앱의 `OCR 엔진`에서 `PaddleOCR (OpenVINO)`를 선택합니다.
2. `OCR 언어`를 `중국어(간체)` 또는 `일본어`로 선택합니다.
3. 첫 실행 또는 모델이 없는 환경에서는 모델 다운로드/로드 시간이 걸릴 수 있습니다.
4. 번역을 시작해 OCR 결과를 확인합니다.

### 모델 준비

모델 다운로드가 자동으로 실패하거나 오래 걸리면 다운로드 스크립트를 사용할 수 있습니다.

```powershell
.\scripts\download-models.ps1
```

스크립트는 PaddleOCR 모델을 `%APPDATA%\paddleocr-models` 아래에 준비합니다. 앱은 언어별 모델을 로드해 OCR을 수행합니다.

### 속도와 품질

- PaddleOCR은 중국어/일본어의 게임 글꼴, 작은 글자, UI 텍스트를 Windows OCR보다 더 잘 읽는 경우가 많습니다.
- 대신 OCR 처리 시간이 더 길어질 수 있습니다.
- 전체화면 번역처럼 OCR 범위가 넓을수록 체감 지연이 커질 수 있습니다.
- 지연이 크면 `영역 선택`으로 범위를 좁히거나 `제외 영역`을 추가하세요.

## OCR 품질을 높이는 방법

- 번역 영역을 글자 주변으로 좁힙니다.
- 움직이는 배경, 반투명 UI, 효과가 많은 영역을 피합니다.
- 닉네임이나 고정 UI는 제외 영역으로 빼 둡니다.
- 밝은 글자/어두운 배경처럼 대비가 좋은 화면에서 인식률이 좋아집니다.
- OCR이 잘못 읽은 반복 표현은 [유저 사전](유저사전.md)에 등록해 보정합니다.
