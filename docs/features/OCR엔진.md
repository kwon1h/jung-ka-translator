# 게임 언어와 모델

번역 화면의 `게임 언어 및 번역 언어`에서는 게임 원문 언어와 결과 언어만 선택합니다. OCR 엔진을 고르거나 별도 설정을 바꿀 필요는 없습니다.

![게임 언어와 모델 상태](../images/app-main-language-model.png)

## 게임 언어와 모델

1. `언어 모델` 드롭다운에서 필요한 언어를 고르고 다운로드합니다.
2. `게임 언어`에서 내려받은 언어를 선택합니다.
3. `번역 언어`를 선택합니다.
4. 모델 상태를 확인하고 번역을 시작합니다.

언어별 모델은 사용자 데이터 폴더에 보관되므로 한 번 준비하면 다음 실행에도 다시 받을 필요가 없습니다.

## 모델 준비

- **게임 언어**에는 이미 내려받은 언어만 표시됩니다.
- **언어 모델** 드롭다운은 중국어(간체), 영어, 일본어, 한국어, 아랍어, 힌디어, 타밀어, 텔루구어, 칸나다어를 제공합니다.
- 준비된 모델은 버튼이 **준비됨**으로 비활성화됩니다. 아직 없는 모델만 **다운로드**할 수 있습니다.

모델은 `%APPDATA%\paddleocr-models` 아래에 저장됩니다. 다운로드에 실패하면 네트워크 연결을 확인한 뒤 해당 언어를 다시 선택해 시도하세요.

## OCR 품질을 높이는 방법

- 번역 영역을 글자 주변으로 좁힙니다.
- 장식·미니맵·순위표처럼 번역하지 않을 곳은 제외 영역으로 추가합니다.
- 작은 글자는 흐릿한 화면보다 대비가 높은 화면에서 더 잘 읽힙니다.
- 반복해서 잘못 읽히는 이름이나 용어는 [유저 사전](유저사전.md)에 등록합니다.

## 성능 참고

- 전체화면 번역은 넓은 화면을 읽으므로 채팅 번역보다 처리량이 큽니다.
- 화면에 중국어·일본어가 없으면 오버레이에 번역을 표시하지 않습니다.
- 지연이 크면 번역 영역을 줄이고 제외 영역을 추가하세요.
