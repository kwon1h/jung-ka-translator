# 유저 사전

유저 사전은 자주 나오는 원문을 원하는 한국어 표현으로 직접 바꾸는 기능입니다. 게임 용어, 빠른 답장, OCR이 자주 틀리는 표현을 등록하면 번역 품질을 안정화하고 API 호출도 줄일 수 있습니다.

![유저 사전에서 사용할 게임 화면 예시](../images/app-main-language-model.png)

## 동작 방식

- 원문과 정확히 일치하는 표현이 있으면 번역 API를 호출하지 않고 사전의 한국어 표현을 사용합니다.
- 채팅 번역과 전체화면 번역 모두에서 사전이 적용됩니다.
- 기본 사전은 앱에 포함되어 있고, 사용자가 추가한 개인 사전은 로컬에 따로 저장됩니다.
- 사전 항목은 `분류`, `원문 단어`, `대체 번역어`로 관리합니다.

## 직접 추가

1. 앱에서 `사전` 탭을 엽니다.
2. `분류`를 선택합니다.
3. `원문 단어`에 OCR 또는 게임 화면에서 나오는 원문을 입력합니다.
4. `대체 번역어`에 표시할 한국어 표현을 입력합니다.
5. `사전 단어 추가`를 누릅니다.

이미 같은 원문이 등록되어 있으면 중복 추가되지 않습니다. 기존 항목을 바꾸려면 해당 항목을 삭제한 뒤 다시 추가하세요.

## 화면 OCR로 채우기

원문을 직접 타이핑하기 어렵거나 중국어/일본어 문자를 정확히 입력하기 힘들 때 쓰는 기능입니다. 원하는 화면 영역을 캡처해 수동 OCR을 한 뒤, 인식 결과를 `원문 단어` 입력칸에 채워 줍니다.

### 사용 흐름

1. `게임 창 선택`에서 OCR할 게임 창을 선택합니다.
2. 내려받은 게임 언어를 원문에 맞게 선택합니다.
3. `유저 사전` 탭으로 이동합니다.
4. `화면 OCR`을 누릅니다.
5. 게임 화면에서 사전에 넣고 싶은 글자 영역을 드래그합니다.
6. OCR 결과가 `원문 단어` 입력칸에 들어갑니다.
7. `대체 번역어`를 입력하고 `사전 단어 추가`를 누릅니다.

번역 세션이 실행 중이면 사전 OCR을 위해 번역을 잠시 멈출 수 있습니다. OCR이 끝나면 다시 번역을 시작하세요.

### 잘 인식시키는 방법

- 글자만 포함되도록 영역을 좁게 잡습니다.
- 한 번에 너무 긴 문장을 잡기보다 단어 또는 짧은 표현 단위로 등록합니다.
- 배경 장식, 아이콘, 반투명 UI가 섞이지 않게 합니다.
- OCR 결과가 틀리면 입력칸에서 직접 수정한 뒤 저장합니다.

## 기본 사전

기본 사전 원본은 `docs/user_dictionary.csv`입니다. 앱 빌드 시 exe 내부 리소스로 포함되며, 배포 폴더에 별도 CSV 파일로 복사되지 않습니다.

`기본 사전 추가` 버튼을 누르면 빠진 기본 항목을 개인 사전에 다시 추가할 수 있습니다. 이미 있는 항목은 중복 추가되지 않습니다.

## 저장 위치

| 데이터 | 위치 |
| --- | --- |
| 기본 사전 원본 | `docs/user_dictionary.csv` |
| 개인 유저 사전 | `%LOCALAPPDATA%\GameOverlayTranslator\user_dictionary.csv` |

개인 유저 사전은 런타임 사용자 데이터입니다. 기본 사전 원본과 별개로 관리됩니다.

## 운영 팁

- 자주 나오는 게임 용어는 짧은 단어 단위로 등록합니다.
- 빠른 답장은 실제 게임에서 쓰는 표현 그대로 등록합니다.
- OCR이 자주 틀리는 표현은 틀린 OCR 결과도 원문으로 등록하면 보정 효과가 있습니다.
- 전체 문장을 너무 많이 등록하면 비슷한 표현에는 적용되지 않을 수 있습니다.
- 사전으로 처리된 문구는 번역 API 요청 수와 문자 수를 줄이는 데 도움이 됩니다.

## 문제 해결

| 증상 | 확인할 점 |
| --- | --- |
| OCR 결과가 비어 있음 | 게임 창과 OCR 언어를 확인하고 글자 영역만 다시 선택합니다. |
| 사전 항목이 적용되지 않음 | 실제 OCR 결과와 사전 원문이 정확히 일치하는지 진단 로그로 확인합니다. |
| 저장한 사전이 사라진 것처럼 보임 | `%LOCALAPPDATA%\GameOverlayTranslator\user_dictionary.csv`가 있는지 확인합니다. |
| 기본 사전 항목이 부족함 | `기본 사전 추가`를 눌러 누락된 기본 항목을 복원합니다. |
